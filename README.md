## 🛠️ How to Run Locally

### 1. Run Python Foundation & Analytics Scripts:
```bash
cd "03_Python_Masterclass"

# Run any script directly
python 01_python_syntax_and_control_flow.py
python 02_python_collections_data_structures.py
python 11_data_cleaning_and_wrangling.py
python 12_exploratory_data_analysis_eda.py
python 15_python_sql_database_pipeline.py
```

### 2. Run the SQL Interactive Runner:
```bash
python 02_SQL_Mastery/sql_interactive_runner.py
```

### 3. Launch the Vibe Coding AI Web App:
```bash
python 07_Vibe_Coding_Sprint/vibe_ai_app/app.py
# Open browser at: http://localhost:8080
```
