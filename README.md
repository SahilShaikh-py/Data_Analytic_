# 🐍 Python Complete Master Tutorial (Beginner to Intermediate)

This repository is designed for **beginner to intermediate level students**. It covers all core programming topics, Object-Oriented Programming (OOP), and industry-standard Data Science & Analytics libraries with fully runnable code and detailed, comprehensive **English explanations & comments**.

---

## 📂 Project Structure & Files Index

| File Name | Topic Name | Key Sub-topics Covered |
| :--- | :--- | :--- |
| **`01_modules_builtin_and_standard.py`** | Built-in Modules | `math`, `random`, `datetime`, `os`, `sys`, `json`, 4 Import Styles |
| **`my_calculator.py`** | Helper Custom Module | User-defined functions, Constants, Helper Class, `__name__ == '__main__'` |
| **`02_user_defined_modules.py`** | Custom Modules Usage | Custom module imports, Aliasing, `dir()`, Inspection, Best practices |
| **`03_classes_and_objects.py`** | Class & Object Basics | `__init__` constructor, `self`, Instance/Class variables, `@classmethod`, `@staticmethod`, `__str__` & `__repr__` |
| **`04_oops_4_pillars.py`** | OOP 4 Pillars | **Encapsulation** (Private `__`, Getters/Setters), **Abstraction** (`abc.ABC`), **Inheritance** (Single, Multilevel, Multiple, `super()`), **Polymorphism** (Overriding, Operator overloading) |
| **`05_numpy_complete_guide.py`** | NumPy Master Guide | 1D/2D/3D Arrays, `zeros`, `ones`, `arange`, `linspace`, Slicing, Reshaping, Vectorization, Broadcasting, Statistical functions, Boolean Indexing |
| **`06_pandas_complete_guide.py`** | Pandas Master Guide | Series, DataFrame, `.loc` vs `.iloc`, Filtering, Adding/Renaming columns, Missing data handling (`fillna`, `isna`), `groupby()`, `merge()` |
| **`07_matplotlib_complete_guide.py`**| Matplotlib Visualization| Line Plot, Bar Chart, Scatter Plot, Histogram, Pie Chart, Subplots dashboard, Figure customization & saving PNGs |
| **`08_seaborn_complete_guide.py`** | Seaborn Statistical Plots | Themes, `histplot`, `kdeplot`, `countplot`, `barplot`, `boxplot`, `violinplot`, `scatterplot`, `heatmap` (Correlation), `pairplot` (EDA) |

---

## 🚀 How to Run the Files

Each file is self-contained and directly executable. Open your Terminal / PowerShell in this directory and execute the following commands:

```powershell
# 1. Test Built-in Modules
python 01_modules_builtin_and_standard.py

# 2. Inspect User-Defined Modules
python 02_user_defined_modules.py

# 3. Run Class & Object concepts
python 03_classes_and_objects.py

# 4. Explore OOP 4 Pillars
python 04_oops_4_pillars.py

# 5. Run NumPy Array operations
python 05_numpy_complete_guide.py

# 6. Run Pandas Data manipulation
python 06_pandas_complete_guide.py

# 7. Generate Matplotlib charts (Saves high-res PNGs)
python 07_matplotlib_complete_guide.py

# 8. Generate Seaborn statistical charts (Saves high-res PNGs)
python 08_seaborn_complete_guide.py
```
