## 📂 Ready-to-Use Star Schema Datasets (`data/`)

Inside the [`data/`](file:///d:/YSM%20Info%20Solution/Data%20Analytics%20&Cyber%20Security/python/03_Power_BI_Mastery/data/) directory:
- `sales_data_1000.csv`: Fact table containing 1,000 transaction records with OrderID, CustomerID, ProductID, Quantity, and Dates.
- `customer_dim.csv`: Dimension table with Customer details, City, State, and Customer Segment.
- `product_dim.csv`: Dimension table with Product Name, Category, Sub-Category, and Unit Price.
- `unpivot_exercise_data.csv`: Exercise table for practicing Power Query wide-to-tall unpivoting.
- `cyber_security_logs_1000.csv`: Specialized dataset for security incident analysis.
